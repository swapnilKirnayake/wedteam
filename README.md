# WedTeam

WedTeam is a wedding-professional marketplace prototype where customers can build their own wedding team by selecting individual professionals.

Instead of hiring an entire event-management company, users can discover and combine professionals based on their needs.

## Concept

The core experience is:

Discover → View Profile → Add to Team → Review Team → Get Contact Details

Professionals can include:

- Wedding Planners
- Photographers
- Videographers
- Makeup Artists
- Decorators
- Caterers
- DJs
- Choreographers

## Prototype Features

- Professional marketplace
- Search professionals
- Category filtering
- Professional profile modal
- Ratings and reviews
- Skills and experience
- Hourly pricing
- Add professionals to team
- Remove professionals from team
- Live team count
- Estimated hourly team cost
- Responsive design
- Mobile navigation
- Monochrome UI
- Grayscale professional photography
